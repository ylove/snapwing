# Snapwing

Snapwing is a Slack and Teams native pipeline that turns a bug-shaped message into a Jira ticket, a fix, a pull request, and a status loop back to the person who reported it. It reads the thread around the message, screenshots included, asks back only when it has to, checks for duplicates, and hands a structured implementation request to a coding agent. An autonomy dial runs from ticket-only to autopilot merge, set per surface, component, and priority.
